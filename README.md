# AluraGeek

**AluraGeek** es una aplicación desarrollada como parte del **Challenge Front-End** del programa **ONE - Oracle Next Education y Alura LATAM**. El objetivo del proyecto es simular una tienda online donde los usuarios puedan listar, agregar y eliminar productos, utilizando tecnologías web como HTML, CSS y JavaScript.

---

## 🚀 **Funcionalidades**

- **Visualización de Productos:** Los productos se muestran en un diseño responsivo, organizados en tarjetas con sus imágenes, nombres y precios.
- **Agregar Productos:** A través de un formulario, se pueden añadir productos personalizados indicando el nombre, precio e imagen.
- **Eliminar Productos:** Cada tarjeta incluye un botón para eliminar el producto correspondiente.
- **Backend Simulado:** Uso de `JSON Server` para simular un API REST y manejar las operaciones CRUD (Crear, Leer, Actualizar, Eliminar).
- **Diseño Responsivo:** Adaptado para pantallas de diferentes tamaños, incluyendo dispositivos móviles.

---

## 🛠️ **Tecnologías Utilizadas**

- **HTML**: Estructura semántica del proyecto.
- **CSS**: Estilizado del diseño con enfoque en responsividad y diseño atractivo.
- **JavaScript**: Lógica para interactuar con el DOM y realizar solicitudes a la API.
- **JSON Server**: Simulación de backend para pruebas de funcionalidad.
- **Google Fonts**: Tipografía personalizada (`Press Start 2P` y `IBM Plex Mono`).
